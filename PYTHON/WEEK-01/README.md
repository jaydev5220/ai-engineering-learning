# Week 01 — Python Fundamentals I

**Planning dates:** 30 November–6 December 2026  
**Goal:** become comfortable creating and running basic Python scripts.  
**Primary resource:** [Harvard CS50P](https://cs50.harvard.edu/python/)  
**Practice:** [Exercism Python](https://exercism.org/tracks/python)

Work through tasks in order whenever free time is available. Dates are planning guidance, not deadlines.

## 1. Environment
- [ ] Install Python 3; record `python --version` here.
- [ ] Install VS Code and the Python extension.
- [ ] Create a project folder and virtual environment.
- [ ] Activate the environment and verify the interpreter.
- [ ] Create and run `examples/hello.py` from the terminal.

## 2. Output, variables and types
- [ ] Use `print()` and comments. Exercise: print a 5-line introduction. Evidence: `examples/output_and_comments.py`.
- [ ] Learn variable assignment and naming conventions. Exercise: store name, role, learning goal and start date. Evidence: `examples/variables.py`.
- [ ] Learn `str`, `int`, `float`, `bool`. Exercise: create and print one value of each type. Evidence: `examples/data_types.py`.
- [ ] Learn `type()` and conversions. Exercise: convert an entered age and calculate next year's age. Evidence: `examples/type_conversion.py`.
- [ ] Learn arithmetic operators and precedence. Exercise: two-number calculator. Evidence: `examples/calculator.py`.

## 3. Strings and input
- [ ] Learn concatenation and f-strings. Exercise: formatted profile summary. Evidence: `examples/strings.py`.
- [ ] Learn indexing, slicing and common methods. Exercise: normalize a name and extract text. Evidence: `examples/string_operations.py`.
- [ ] Learn `input()` and safe numeric conversion. Exercise: terminal user profile form. Evidence: `examples/user_profile.py`.

## 4. Mini-project
- [ ] Build a terminal-based personal profile app using variables, types, strings and input.
- [ ] Ask for name, role and learning goal.
- [ ] Validate required inputs.
- [ ] Format and print a clean summary.
- [ ] Test normal input and at least two invalid input cases.
- [ ] Add a README explaining how to run it.

## 5. GitHub evidence
- [ ] Commit each meaningful exercise.
- [ ] Push code to this learning repository.
- [ ] Paste commit links in the progress log.
- [ ] Update the main `PROGRESS.md`.
- [ ] Write the weekly review.
