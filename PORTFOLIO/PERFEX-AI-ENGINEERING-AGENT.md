# Portfolio Project — Perfex AI Engineering Agent

The product source remains in its own repository: [perfex-ai-engineering-agent](https://github.com/jaydev5220/perfex-ai-engineering-agent).

This learning repository records the skills, experiments and evidence acquired while improving that product. Do not move or duplicate product source code here.

## Learning-to-project map

| Learning phase | Application to the Perfex AI Agent | Evidence to record here |
|---|---|---|
| Python | Utility scripts, data processing and backend services | Small isolated Python exercises |
| FastAPI and testing | Typed APIs, validation and integration tests | API design and test notes |
| ML and LLM | Model selection and experimentation | Model experiment reports |
| Prompt/context engineering | Reliable instructions and context assembly | Prompt experiments and test cases |
| RAG | Index Perfex documentation and code | Retrieval experiments, metrics and examples |
| Agents | Tool-driven CRM actions and workflows | Agent behavior test cases |
| MCP | Expose approved CRM capabilities as tools | MCP server demo and schemas |
| Harness engineering | Execution loop, checkpoints and recovery | Failure/recovery test report |
| Inference/LLMOps | Local inference, performance and monitoring | Benchmark and observability report |
| Security/evals | Least privilege, prompt injection tests and regression suite | Threat model and evaluation results |
| System design | Production architecture and scaling | Architecture decision records |
